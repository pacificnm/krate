# Kessel: roadmap

Each milestone ends with something you can run and check, and is committed and pushed when done. Korrode's golden renders and the rack tests must stay green throughout.

| # | Milestone | Done when |
| --- | --- | --- |
| D0 ✅ | **Skeleton** | `instruments/kessel/` (`kessel_dsp`, `kessel_ui` QML module `Kessel`) and `apps/kessel/`; registry entry; `pw-jack ./build/bin/kessel` opens the empty panel, scaled, with the header and section labels, a JACK client `kessel` with `out_L/R` and `midi_in`, silent. Result: parameter table (31), silent `Engine` with MIDI Learn CCs, `Drums` controller (Tempo and START/STOP drive the standalone transport), registry entry (channel 10, actions `patternA`–`patternH`, `startstop`), `tst_kessel`; verified in the app: JACK outputs and both LX49 ports connect |
| D1 ✅ | **Voices** | All 11 voices in [DSP.md](DSP.md); `kessel-render` writes a WAV of every voice in turn and a demo beat; `tst_voices`: each voice is non-silent, bounded, decays to silence, deterministic, little energy above 20 kHz; `--bench` within budget. Result: all voices, plus MIDI notes (velocity, accent at ≥ 100, sample-accurate) from D2 and the knobs from D0; `tst_voices` (also choke, retrigger without clicks, Volume); under 0.6% of the energy above 20 kHz; bench 1.05% of a core with all 11 voices on every beat |
| D2 ✅ | **Panel and notes** | Every knob on the panel and wired (`Drums` controller on `ParamController`, `panel.json`) (done in D0); MIDI notes play the voices with velocity and accent (done in D1); right-click on a track name auditions it; knob style closer to the reference (black, orange pointer); screenshot matches the layout in [UI.md](UI.md). Result: audition goes through a new lock-free command queue (`Engine::post`, which D3-D4 extend with pattern edits); `Knob` gained cap and pointer colors (Korrode unchanged) |
| D3 ✅ | **Sequencer** | Tracks × steps playback on `StepClock` with accent, Total Accent, Shuffle, hat choke, play order and scale; step LEDs; START/STOP and Space; a golden render of a fixed pattern; `tst_sequencer` (step timing to the sample, shuffle offsets, choke, pattern change at the end of the pass). Result: all of that except pattern change (moves to D4 with A–H). Pulled forward from D4: track select (click a name, ↑ ↓), step toggling off → on → accent, CLEAR (Shift: whole pattern). Four factory patterns; pattern 0 loads at startup. `kessel-render --pattern N` renders through the sequencer and transport (reference renders saved for byte comparison). Shuffle uses `StepClock`'s gate point and its new `stepCount()`. Play order has no panel control yet (Forward) |
| D4 ✅ | **Patterns and storage** | A–H (change at the end of the pass while playing), length, scale, play order; `patterns.json` with the factory patterns seeded on first run (`tst_pattern`). Result: as planned; the waiting pattern is editable (edits name their slot), Clear replaces the pattern in one queue item, keys A–H. Tests in `tst_kessel` (file format, clamping, save and restore through the controller) and `kessel_tst_sequencer` (pass boundary, order restart, cancel, edits to the waiting pattern). `StepClock::restartPass()` added to the shared clock |
| D5 ✅ | **MIDI Learn and the rack** | Learn for all knobs, A–H and `startstop`; Kessel in the Krate rack on channel 10 (Tempo and START/STOP hidden there); `krate-render` includes it; rack tests extended; on the LX49, pads play Kessel on channel 10 while the keys play the focused instrument. Result: UNMAP / AUDIO / LEARN, status line and meter on the panel (L, Esc); START learnable as `startstop`; Kessel between Korrode and Klick in the rack (saved mappings are keyed by id, so existing sessions keep working); `krate-render --kessel LEVEL [--kessel-pattern N]` (without it the render is byte-identical to before); `kessel_tst_rack` (channel 10 reaches Kessel whatever has focus). Kessel includes are now `kessel/dsp/...`, `kessel/app/...`, since Korrode has files of the same names. LX49 pads: to be confirmed on the hardware |
| D6 ✅ | **Polish** | Voices tuned by ear (DSP.md updated with final values); qmllint clean; accessibility names; README section. Result: −3 dB output trim for headroom (demo beat peaks at −3.5 dBFS before the soft clip); accessible names everywhere (`ParamController::label()`, `LcdField.name`, full-word parameter labels); step buttons keyboard-reachable; DSP.md and README updated; qmllint clean. Ear tuning continues from listening feedback (see Later) |

| D7 ✅ | **Engine** | Kick SWEEP / BEND / TONE, snare DECAY / CRACK, rim and clap TUNE / DECAY, clap SPREAD, hat TUNE; a MIX page (per-voice PAN, DRIVE, REVERB and DELAY sends); the gated reverb, delay, bus compressor and crusher; 92 parameters (`ParamValues` past 64). Result: every new control defaults to the original kit (all reference renders byte-identical); `kessel_tst_character` |
| D8 ✅ | **Industrial voices and kits** | METAL, CLANK, NOISE, BOOM; 16 kits with six factory kits (Classic, Industrial, EBM, Gated 80s, Crushed, Machine Shop), KIT display and WRITE; patterns I–P with eight industrial factory patterns. Result: 123 parameters; every factory kit on every factory pattern measured (all peaks under 0 dBFS); the compressor's makeup raised to ¾ of the reduction; bench 1.9 % (15 voices), 3.4 % with everything on ([KITS.md](KITS.md)) |
| D9 ✅ | **Step details** | Flam (a fourth step state), per-step velocity, tune and decay locks; the step editor (right-click a step); stored in `patterns.json`. Result: as planned; flam's main hit 18 ms after a 60 % grace hit; patterns without details render byte-identically; tests in `kessel_tst_sequencer` and `tst_kessel` |
| D10 ✅ | **Sample voice** | A 16th voice, SAMPLE, playing a WAV file of your own: TUNE, LEVEL, DECAY, START, its mixer strip and track; LOAD (file dialog) and drag-and-drop import into a sample library; kits remember their sample. Result: the WAV reader moved from Krunch to the shared library (`krate::readWavFile`); samples handed to the engine through an atomic and freed two blocks after a swap; the classic patterns still render byte-identically; bench 1.9 %; tests for playback (pitch, start, decay, swap), the library (import, refusal, persistence) and kits |
