# Konnekt: roadmap

Each milestone ends with something you can run and check, and is committed and pushed when done.

| # | Milestone | Done when |
| --- | --- | --- |
| N1 ✅ | **The engine** | `konnekt_dsp`: modules described by tables (jacks, knobs, help text); the patch graph (modules, cables, signal order, one block of delay round a loop); voices and the MIDI In module; Oscillator, Envelope, LFO, VCA, Mixer, Attenuverter, Output; patch changes handed to the audio thread without locks; live taps on every output; `konnekt-render` plays a patch to WAV; `konnekt_tst_engine` (pitch 1 per octave, voices, a per-voice cable into a one-voice input mixes, loops delay one block, unplugged inputs read their knobs). Result: as planned; `konnekt-render` plays a built-in patch (patch files arrive with N4); patches are built from plain data (`PatchSpec`, no Qt) for the renderer, the tests and the app; a stolen voice's gate closes for one block so envelopes start again; 8 voices of two oscillators, an LFO, a mixer, an envelope and a VCA: 3.4 % of a core; `konnekt_tst_engine` (16 tests, including every module's help text being there and every module fed by everything at once staying finite) |
| N2 ✅ | **The other modules** | Noise, the three filters, Sample & hold, Slew, Drive, Crusher, Ring mod, Clock, Sequencer, Chorus, Delay, Reverb, Scope; each tested. Result: as planned, all 23 modules; the ladder is Kalliope's and the OTA filter Kobalt's, as they are; the sequencer has 8 steps (a pitch and on / off each, length, gate length) rather than 16, to keep its panel playable; a crusher at n bits now gives exactly 2^n levels (Klang's too: rounding a full-scale wave had given one more); `konnekt_tst_modules` (15 tests: the filters cut and pass, sample & hold holds, slew glides, the clock ticks to the sample, the sequencer steps, rests and wraps, the delay echoes on time, the stereo effects make two sides) |
| N3 ✅ | **The app** | The `konnekt` app on JACK: the rack of modules drawn from their tables, add / move / delete, click-to-wire cables, live traces on the jacks, a scope on a cable, help on hover, VOICES, MIDI Learn for knobs. Result: as planned; panels are drawn from the module tables (two-position controls as buttons; the sequencer 8 columns wide: each step's note over its on / off); jacks coloured by what they carry (audio orange, pitch blue, gates green, modulation violet), outputs with a 1.5 s trace; cables sag between jacks; a plugged input lifts its cable when clicked; right-click an output for the scope (a Scope module shows its own); every module, knob and jack explains itself in the help bar; MIDI Learn per knob, saved with the patch; the patch in use kept in `current.json`; it connects to every MIDI controller; `konnekt_tst_konnekt` (5 tests: the first patch plays, cables replace, knob texts, the patch round-trips) |
| N4 ✅ | **Patches and lessons** | Save / load by name; lesson patches with their explanations; the manual (HELP); README and the suite docs. Result: as planned; PATCHES saves and loads by name (`~/.local/share/konnekt/patches/*.json`, names made safe for files); LESSONS: ten patches with their explanations (a tone; notes that start and stop; the filter; a filter envelope; LFOs; two oscillators; FM; a sequenced bass line; noise percussion; effects), each loaded with its text in a panel, ◂ ▸ through them; HELP opens the manual; `konnekt_tst_konnekt` loads every lesson whole (no unknown module, jack or knob) and plays it (8 tests) |
